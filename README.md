# Портфолио — карта проектов

> Личная коллекция проектов: веб-приложения, боты, лендинги и эксперименты.
> Основной сайт-портфолио: [auryxn.codes](https://auryxn.codes) — репозиторий сайта [site-admin](https://github.com/auryxn/site-admin).

Этот репозиторий — **навигационная карта**: список всех проектов со ссылками на
их репозитории, кратким описанием, стеком и статусом. Исходный код каждого
проекта лежит в собственном публичном репозитории.

- **Владелец:** [auryxn](https://github.com/auryxn)
- **Профиль-портфолио:** [auryxn.codes](https://auryxn.codes)

---

## Проекты

### 🎬 AI Creative Studio — [репозиторий](https://github.com/auryxn/ai-creative-studio)
Рабочее место AI-режиссёра: производство фильмов на нейросетях — от идеи и
сценария до сцен, персонажей, промптов и ассетов в одном интерфейсе.
**Стек:** Next.js 15 · React 19 · TypeScript · Tailwind. **Статус:** MVP.

### 🗺️ BarLink — [репозиторий](https://github.com/auryxn/barlink)
Веб-MVP знакомств в барах: карта заведений Вильнюса, создание встречи или
присоединение к чужой, участники и групповой чат.
**Стек:** React 18 · Vite · Tailwind · Leaflet · Node/Express · SQLite. **Статус:** MVP.

### 🎥 Content Factory — [репозиторий](https://github.com/auryxn/content-factory)
Локальный «контент-завод»: режет длинные видео на клипы под TikTok, накладывает
фоновую музыку и ведёт расписание публикаций через веб-дашборд.
**Стек:** Python · FastAPI · Uvicorn · ffmpeg. **Статус:** рабочий инструмент.

### ⭐ FilmRank — [репозиторий](https://github.com/auryxn/filmrank)
Личный рейтинг фильмов и сериалов: свайпы в стиле Tinder + попарные дуэли для
точного ранжирования, tier-список и статистика вкуса.
**Стек:** Vite · React 19 · framer-motion · TMDB · localStorage. **Статус:** готов.

### 📚 Homework Hub — [репозиторий](https://github.com/auryxn/homework-hub)
Локальная доска учебных заданий из Microsoft Teams с автозапуском
агентов-исполнителей по предметам и потоковым логом прогресса.
**Стек:** Node.js (stdlib) · статический HTML/CSS/JS · CDP · OpenClaw-агенты. **Статус:** рабочий инструмент.

### 🌐 Город-Интернет (internet-city) — [репозиторий](https://github.com/auryxn/internet-city)
Интерактивная 3D-визуализация того, как интернет доставляет данные: путь
запроса от ввода адреса до отрисовки страницы, в 10 шагов, с режимами
«просто/технически», симуляцией потери пакета и квизом.
**Стек:** Vite · TypeScript · Three.js. **Статус:** готов.

### 🤖 ShiftBot — [репозиторий](https://github.com/auryxn/shiftbot)
Telegram-бот для краткосрочных подработок: админ публикует смены, работники
записываются в пару кликов, напоминания и автозакрытие смен.
**Стек:** Python 3.12 · aiogram 3 · PostgreSQL · SQLAlchemy 2 · Alembic. **Статус:** MVP.

### ☕ Velora Café — [репозиторий](https://github.com/auryxn/velora-cafe)
Сайт кофейни с редактируемой админкой: публичная страница + REST API с
управлением меню, отзывами, галереей и бронированиями.
**Стек:** React · Vite · Tailwind · Node.js (stdlib) · SQLite. **Статус:** готов.

### 🍽️ Kavinė Koralai — [репозиторий](https://github.com/auryxn/kavine-koralai)
Demo svetainė Karoliniškių kavinei (lietuvių k.): dienos meniu, galerija,
banketai, kontaktai. Vienas `index.html` failas.
**Стек:** HTML · CSS · JS (один файл). **Статус:** демо-макет.

### 🍺 Baltic Brew — [репозиторий](https://github.com/auryxn/baltic_brew_preview)
Одностраничный демо-лендинг крафтового бара в Вильнюсе: 12 кранов,
ротирующийся ассортимент, настольные игры, контакты.
**Стек:** HTML · CSS · JS (один файл). **Статус:** демо-лендинг.

## Основной сайт

### 🖥️ auryxn / site-admin — [репозиторий](https://github.com/auryxn/site-admin)
Личный сайт-портфолио в стиле Web 1.0 + админ-панель с редактируемым
